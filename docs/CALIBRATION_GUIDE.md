# Touchpad Magnetic Calibration — Quick Guide

Maps the synthetic dipole field generated by the touchpad simulator onto the
real sensor channels, so that touchpad recordings produce magnetic data that
matches the real hardware layout.

---

## When to calibrate

Run this **once per lab session** (or whenever the hardware position changes).
The calibration JSON is then passed to every `--record-data` run.

---

## Step 1 — Record the calibration CSV

Connect the real sensor hardware and move the magnet slowly over the full pad
in a grid pattern (cover corners, edges, and centre at several heights).

```bash
python magnetometer_reader.py \
  --input-source serial \
  --csv data/lab_$(date +%Y-%m-%d)/raw/magcal_$(date +%H%M)_raw.csv
```

**Tips for a good calibration recording:**
- Cover the full XY extent of the sensor pad (all four corners + centre).
- Include at least 3 different heights (Z values).
- Move slowly and steadily — fast flicks produce noisy samples.
- Aim for 500–5000 rows (a few minutes of slow scanning is fine).

---

## Step 2 — Fit the calibration

```bash
python tools/calibrate_touchpad_magnetics.py \
  data/lab_2026-05-20/raw/magcal_0930_raw.csv
```

The script prints a per-sensor RMSE table and a quality badge:

| Badge       | Global RMSE       | Meaning                               |
|-------------|-------------------|---------------------------------------|
| EXCELLENT   | < 1e-8            | Near-perfect fit                      |
| GOOD        | 1e-8 – 1e-6       | Ready to use                          |
| ACCEPTABLE  | 1e-6 – 1e-4       | Usable; re-record if possible         |
| POOR        | > 1e-4            | Re-record with better coverage        |

Output file: `data/lab_2026-05-20/raw/touchpad_magnetic_calibration.json`

Optional flags:
```bash
# custom output path
--output path/to/my_calibration.json

# if your pad extent differs from the default 0.05 m
--projection-extent 0.04
```

---

## Step 3 — Use the calibration (touchpad simulator)

```bash
# live view with calibrated magnetics
python magnetometer_reader.py \
  --input-source touchpad \
  --touchpad-magnetic-calibration data/lab_2026-05-20/raw/touchpad_magnetic_calibration.json

# with data recording
python magnetometer_reader.py \
  --input-source touchpad \
  --touchpad-magnetic-calibration data/lab_2026-05-20/raw/touchpad_magnetic_calibration.json \
  --record-data \
  --output-dir data/lab_2026-05-20/ \
  --run-id run_001
```

---

## Verify the calibration is loaded

At startup the reader prints:

```
Loaded touchpad magnetic calibration: path/to/touchpad_magnetic_calibration.json
```

If this line is missing, the calibration was not applied.

---

## Troubleshooting

| Problem                         | Likely cause & fix                                         |
|---------------------------------|------------------------------------------------------------|
| POOR quality                    | Sparse coverage — scan more of the pad at more heights     |
| `No usable rows found`          | CSV header mismatch — check `Sensor1_Bx` column names      |
| `Need at least 4 finite samples`| All rows have NaN values — check sensor connection         |
| Calibration file not found      | Wrong path passed to `--touchpad-magnetic-calibration`     |
